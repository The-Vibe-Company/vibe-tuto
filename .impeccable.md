## Design Context

### Users
A person records a software demonstration; an agent authors a guide for a new
colleague. Readers need clear instructions, screenshots and a useful portable PDF.

### Brand Personality
Simple, warm, distinctive. The interface should feel calm and dependable.

### Aesthetic Direction
Reference: https://companions.build/. Warm light surfaces, strong dark typography,
space and restrained coral accents. Mac uses native controls and supported Liquid
Glass with a fallback. Web retains shadcn and Tailwind.

### Design Principles
- One clear next action in each recorder state.
- Instructions and captures take precedence over decoration.
- Show real progress and actionable recovery; no decorative settings.
- Same authored content and annotations across editor, preview, share and PDF.
- Respect contrast, reduced motion and keyboard navigation.
